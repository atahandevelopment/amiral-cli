# Conventions

Established during SETUP-001 (scaffold of `apps/web`).

## Language

- Code, comments, and commit messages: **English**.
- User-facing UI strings: **German**, sourced from content data in `src/content` (not hardcoded in components).

## Import alias

- `@/*` resolves to `apps/web/src/*` (configured in `tsconfig.json` paths and `components.json`).

## Folder structure

- `src/components/ui` — shadcn/ui primitives (button, input, select, textarea, checkbox, label, accordion, dialog, card, badge, skeleton, separator)
- `src/components/sections` — page sections composed from content
- `src/components/forms` — form components (react-hook-form + zod)
- `src/content` — content data (JSON), generated by the scraper
- `src/lib` — shared helpers (e.g. `cn` in `src/lib/utils.ts`)
- `public/assets` — local images
- `tests/` — Playwright E2E specs
- `scripts/` — scraper and tooling

## Styling

- Tailwind CSS v4 utility classes with shadcn theme tokens (`bg-primary`, `text-muted-foreground`, etc.).
- Use the `cn()` helper (`src/lib/utils.ts`, clsx + tailwind-merge) for conditional class names.
- System font stack via `--font-sans` / `--font-mono` theme variables; no custom font files.

## Forms

- Demo mode only (`FORM_MODE=demo`): submissions are logged to `.data/inbox.json`.
- Form schemas in zod, wired with `@hookform/resolvers` into react-hook-form.

## npm scripts (run inside `apps/web`)

| Script       | Command               | Purpose                                  |
| ------------ | --------------------- | ---------------------------------------- |
| `dev`        | `next dev`            | Development server (Turbopack)           |
| `build`      | `next build`          | Production build                         |
| `start`      | `next start`          | Serve production build                   |
| `lint`       | `eslint`              | ESLint (flat config)                     |
| `typecheck`  | `tsc --noEmit`        | TypeScript check                         |
| `test`       | `vitest run`          | Unit tests (files: `src/**/*.test.ts(x)`)|
| `e2e`        | `playwright test`     | E2E tests (files: `tests/`, port 3100)   |
| `scrape`     | `tsx scripts/scrape/index.ts` | Run the scraper (placeholder yet)  |

## Metadata / SEO

- Root layout: `<html lang="de">`, title template `%s | Volvo Car Bern`, German description.
- Per-page titles set via the Metadata API.

## Testing

- Unit/component tests colocated near the code as `*.test.ts(x)` under `src/` (Vitest + Testing Library + jest-dom).
- E2E tests in `tests/` (Playwright, Chromium, fixed port 3100 via `playwright.config.ts` `webServer`).
